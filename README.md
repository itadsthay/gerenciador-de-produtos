Sistema simples de gerenciamento de produtos desenvolvido em Python. Permite ao usuário cadastrar, remover, pesquisar e visualizar produtos com controle de estoque, preço e data de registro.

Funcionalidades
Cadastrar novos produtos
Remover produtos existentes
Pesquisar um produto pelo nome
Exibir todos os produtos cadastrados
Mostrar descrição, preço, estoque e data de registro
Contar o total de produtos cadastrados

Como executar
Clone o repositório ou copie o código para um arquivo gerenciador-produtos.py
Execute o arquivo em um terminal ou prompt de comando com:
python gerenciador-produtos.py
Siga as instruções no menu exibido.
